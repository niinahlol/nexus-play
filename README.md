# NEXUS PLAY

Uma plataforma web para explorar jogos, descobrir novos títulos, visualizar informações detalhadas e salvar jogos favoritos.

O Nexus Play foi desenvolvido como projeto final integrador do curso de Front-end da FIRJAN SENAI, utilizando REACT, vITE e a API pública RAWG.

## Funcionalidades

- Página inicial com jogos em destaque e populares
- Busca de jogos em tempo real
- Filtro de jogos por gênero
- Página de detalhes de cada jogo
- Galeria de screenshots
- Sistema de favoritos
- Persistência dos favoritos utilizando `localStorage`
- Navegação entre páginas com React Router
- Indicadores de carregamento
- Mensagens de erro e ausência de resultados
- Layout responsivo para diferentes tamanhos de tela

## Tecnologias utilizadas

- React
- Vite
- React Router
- JavaScript
- CSS
- API RAWG
- LocalStorage
- Firebase Hosting

## Como executar o projeto

### 1. Clone o repositório

git clone URL_DO_REPOSITORIO

### 2. Entre na pasta do projeto

cd nexus-play

### 3. Instale as dependências

npm install

### 4. Configure a chave da API

Crie um arquivo `.env` na raiz do projeto:

VITE_RAWG_API_KEY=sua_chave_da_api

### 5. Execute o projeto

npm run dev

Depois, acesse o endereço exibido pelo Vite no terminal.
